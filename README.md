Домашнее задание к занятию «2.4. BDD».

## Задача №1 — Page Object's

Реализованы автотесты функции перевода средств между собственными картами с использованием Selenide и Page Object.

Проверяются:

- получение текущего баланса карт;
- выбор карты для пополнения;
- успешный перевод между собственными картами;
- изменение балансов после перевода;
- запрет перевода суммы, превышающей доступный баланс.

При тестировании обнаружен дефект: приложение позволяет выполнить перевод при недостаточном количестве средств, в результате чего баланс карты может стать отрицательным.

## Обнаруженные дефекты

- [При переводе суммы больше доступного остатка операция выполняется и баланс карты становится отрицательным](https://github.com/SmArt1606/bdd-page-objects/issues/1)

Из-за обнаруженного дефекта негативный автотест завершается с ошибкой. Дефект зафиксирован в GitHub Issues.
